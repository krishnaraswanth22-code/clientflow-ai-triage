Core Engineering Rationale

Why Standard Chatbots Fail in Real Inboxes

  • ✓ Sub-3-Second Autonomous Sweep: Runs headlessly to parse, grade, and respond to standard queries 24/7/365.

  • ✓ Zero UI Disruption: Operates natively inside Gmail using 3 clean labels (🟢 AI Handled, 🟡 Review Drafts, 🔴 Action Needed).

Technical Implementation

System Architecture & Design Decisions

1. Noise Pre-Filtering

Checks headers against vendor blocklists and promotional terms before invoking LLM inference. Truncates bodies to 2,000 chars, eliminating token burn and HTTP 413 exceptions.

2. Schema Enforcement

Constrains model completion to strict Pydantic models (is_complex, confidence_score, suggested_reply) to avoid unpredictable freeform strings.

3. Ephemeral In-Memory

Evaluates email payloads in volatile server memory (RAM) and purges them immediately upon dispatch, adhering to GDPR/CCPA zero-storage standards.
